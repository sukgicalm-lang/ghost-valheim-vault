Ghost r2 하나로 통합팩과 제련 제어를 함께 설치하세요.

WINDOWSGhost r2 1.0.7Valheim 별도 필요
  1. 01

    런처를 준비하세요.

    게임과 기존 런처를 종료한 뒤, 다운로드한 ZIP의 압축을 풀고 INSTALL_GHOST_R2.cmd를 실행하세요.

    Windows용 런처 다운로드

    설치가 끝나면 Ghost r2에서 Valheim → 사용할 프로필을 선택하세요. 1.0.7부터 런처 새 버전은 자동으로 내려받아 적용한 뒤 다시 실행됩니다.

  2. 02

    전체 모드를 설치하세요.

    아래 버튼을 누르고 브라우저의 Ghost r2 열기를 허용하세요. 런처에서 같은 프로필에 설치를 진행합니다.

    런처에서 전체 모드 설치
    Ghost 통합팩 Ghost 제련 제어

    두 모드가 모두 기본 구성입니다. 따로 골라 받을 필요가 없습니다.

    기존 FrizzQOL 제련 모드를 사용하고 있나요?

    같은 프로필의 FrizzQOL Smelter Control을 먼저 제거하세요. Ghost 제련 제어와 동시에 설치하지 마세요.

  3. 03

    이제 모험을 시작하세요.

    모드 목록에서 GhostValheimSuite와 GhostSmelterControl이 모두 활성화되어 있는지 확인한 뒤, 런처의 Start modded를 누르세요.

    다음에 플레이할 때도 Ghost r2에서 같은 프로필로 실행하세요.

1.0.6 이하 런처는 한 번만 새로 설치하세요.

이전 버전에는 런처 자동 업데이트 기능이 없습니다. 1.0.7로 옮긴 뒤부터는 새 런처가 나올 때 자동으로 업데이트하고 다시 실행합니다.

KEEP YOUR WORLD READY

업데이트는 런처에서.

게임을 종료한 뒤 평소 사용하는 Ghost r2 프로필을 여세요.

  1. 1
    새 버전 확인

    런처가 새 모드 버전을 자동으로 확인합니다. 보이지 않으면 버전 확인 버튼을 누르세요.

  2. 2
    Update All

    모두 업데이트를 눌러 설치된 모드를 최신 버전으로 맞추세요.

  3. 3
    Start modded

    업데이트가 끝나면 같은 프로필에서 게임을 실행하세요.

통합팩만 있고 제련 모드가 없어요.

Ghost r2 1.0.6 이상에서 아래 버튼을 누르면 필수 제련 모드를 추가할 수 있습니다. 기존 FrizzQOL Smelter Control은 먼저 제거하세요.

빠진 제련 모드 추가

런처 자동 업데이트 중에는 모드·프로필·개인 설정을 유지합니다. 업데이트를 완료하지 못하면 다시 시도하거나 현재 버전으로 계속할 수 있습니다.
