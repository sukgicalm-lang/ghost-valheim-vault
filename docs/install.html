런처만 설치하세요. 필수 모드 29개는 자동으로 준비됩니다.

WINDOWSGhost r2 1.0.11Valheim 별도 필요
  1. 01

    런처를 준비하세요.

    게임과 기존 런처를 종료한 뒤, 다운로드한 GhostR2-Setup-1.0.11.exe를 실행하세요. 압축을 풀거나 통합팩을 따로 받을 필요가 없습니다.

    Windows용 런처 다운로드

    설치가 끝나면 Ghost r2가 실행되고 Valheim의 마지막 사용 프로필이 열립니다. 처음 사용하는 경우 Default 프로필을 준비합니다.

  2. 02

    자동 준비가 끝날 때까지 기다리세요.

    런처가 필수 모드 29개를 확인하고 빠진 모드를 내려받습니다. 상단에 준비 완료가 표시되면 설치가 끝난 것입니다.

    Ghost 통합팩·제련 제어 생활 편의·필수 라이브러리

    별도로 통합팩을 받거나 모드를 하나씩 추가할 필요가 없습니다. 처음에는 약 400MB를 내려받으므로 연결 상태에 따라 시간이 걸릴 수 있습니다.

  3. 03

    이제 모험을 시작하세요.

    필수 모드 29개 준비 완료를 확인한 뒤 런처의 Start modded를 누르세요.

    다음부터도 Ghost r2를 여세요. 새 배포와 누락된 필수 모드를 자동으로 확인합니다.

1.0.10 이하 런처는 이번에 한 번 새 설치 파일로 교체하세요.

이전 버전의 자동 업데이트 오류를 수정했습니다. 위의 Windows용 런처를 실행하면 기존 프로필과 설정을 유지하며 교체합니다. 1.0.11부터 이후 업데이트는 런처 실행 시 자동으로 적용됩니다.

  1. 1
    런처 자동 업데이트

    새 런처가 있으면 내려받아 적용하고 다시 실행합니다.

  2. 2
    필수 구성 자동 확인

    통합팩·제련 제어와 필수 모드를 자동 설치·업데이트합니다. 이미 준비된 패키지는 다시 받지 않습니다.

  3. 3
    Start modded

    상단의 준비 완료 표시를 확인하고 게임을 실행하세요.

게임이 실행 중이면 모드 변경을 기다립니다. 다운로드에 실패하면 원인이 표시되며, 연결이 복구된 뒤 다시 시도할 수 있습니다.

자동 설치가 멈췄어요.

인터넷 연결을 확인하고 게임과 일반 r2modman을 종료하세요. Ghost r2 상단에 표시된 원인을 확인한 뒤 다시 시도를 누르세요. 이미 받은 모드는 유지하므로 처음부터 전부 받을 필요는 없습니다.

함께 플레이하는데 외형이나 기능이 달라요.

각자 게임을 종료한 뒤 Ghost r2를 열어 준비 완료를 확인하세요. 같은 게임 버전과 공식 필수 구성을 사용해야 합니다. 개인 설정값은 별도로 유지됩니다.

제련 속도와 투입량은 어디에서 바꾸나요?

게임에서 F1을 누르고 Ghost Smelter Control을 선택하세요. Smelter는 제련소, BlastFurnace는 용광로, CharcoalKiln은 숯가마입니다. 기본 생산 시간은 1초, 원료·연료 한도는 100개입니다.

비상 복구 · Ghost 모드 개별 ZIP

자동 설치의 특정 Ghost 모드만 복구할 때 사용하는 파일입니다. 평소에는 받을 필요가 없습니다. 필요한 ZIP을 받아 압축을 풀지 말고 Ghost r2의 Import local mod에서 가져오세요.
