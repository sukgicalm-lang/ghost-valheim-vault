BodyShape의 Valheim은 발헤임 체형, Original은 원본 모델의 신체 비율을 사용합니다.

둠 머리는 얼굴·귀·헤어를 함께 표시합니다. 해제하면 기존 얼굴·헤어로 돌아옵니다. 광전사·해골기사 망토는 망토 부위에서 따로 선택하세요. 둠·군주 탐식자에는 별도 망토가 없습니다. 티리엘 빛의 날개는 망토 외형에서 별도로 선택합니다. 티리엘 장갑은 상의, 장화는 하의에 포함됩니다.

AnimateCapes로 광전사·해골기사의 망토 물리를 켜고 끕니다. Original은 원작 비율을 유지하고 전체 키를 게임 크기에 맞춥니다. 한 부위를 해제해도 다른 부위는 유지됩니다.

티리엘 어깨·팔은 고체 표면 대신 반투명한 불길로 표현합니다. F1 → Ghost Wardrobe → Tyrael Energy에서 움직임·속도·밝기를 조절합니다. 빛의 날개는 Tab → 외형 → 망토에서 선택하고, Tyrael Wings에서 움직임·크기·농도를 조절합니다. 원작 느낌을 목표로 한 발헤임용 근사 표현입니다.

실제 장비 능력치는 유지합니다. 친구도 같은 통합팩 버전으로 맞춰 주세요.
