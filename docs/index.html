VALHEIMORIGINAL
머리·망토 선택과 크기 설정 안내

둠 머리는 다크엘프 얼굴·귀·헤어를 함께 표시합니다. 머리 외형을 해제하면 기존 발헤임 얼굴·헤어로 돌아옵니다. 광전사와 해골기사는 각 세트의 투구를 사용합니다.

광전사·해골기사 망토는 상의와 별개입니다. 외형 창의 망토 부위에서 따로 골라 주세요. AnimateCapes로 천 물리를 켜거나 끌 수 있습니다. 둠에는 망토가 없습니다.

Original 체형의 전체 크기는 OriginalScaleDoom, OriginalScaleBerserker, OriginalScaleSkullKnight로 조절합니다. 서로 다른 게임의 단위 변환 배율이며, 원작 공식 신장과 같은 값은 아닙니다.

실제 장비 능력치는 유지합니다. 이미지는 프로모션 아트이며 게임 화면과 다를 수 있습니다.

설치는 한 번.
그다음부터는 간단하게.

  1. 01

    전용 앱을 준비하세요.

    일반 r2와 게임을 종료하세요. 설치 ZIP을 풀고 INSTALL_GHOST_R2.cmd를 실행하면 Ghost r2가 설치됩니다.

  2. 02

    Valheim과 프로필을 선택하세요.

    앱에서 Valheim → 사용할 플랫폼 → 프로필을 선택하세요. 데이터 경로를 옮겨 쓰고 있다면 Change data folder에서 기존 경로를 선택합니다.

  3. 03

    통합팩 설치를 누르세요.

    브라우저의 앱 열기 요청을 허용하면 선택한 프로필에 통합팩을 설치합니다. 설치를 마치면 앱의 Start modded로 게임을 실행하세요.

이후에는 앱에서 새 통합팩을 자동으로 확인합니다. 새 버전이 있으면 업데이트 버튼을 눌러 적용하세요. 전용 앱 자체의 새 설치 파일은 별도로 배포합니다.
