둠 머리는 얼굴·귀·헤어를 함께 표시합니다. 해제하면 기존 얼굴·헤어로 돌아옵니다. 광전사·해골기사 망토는 망토 부위에서 따로 선택하세요. 둠에는 망토가 없습니다.

AnimateCapes로 망토 물리를 켜고 끕니다. Original 전체 크기는 OriginalScaleDoom / OriginalScaleBerserker / OriginalScaleSkullKnight로 조절합니다.

설치는 한 번.
그다음부터는 간단하게.

  1. 01

    전용 앱을 준비하세요.

    일반 r2와 게임을 종료하세요. 설치 ZIP을 풀고 INSTALL_GHOST_R2.cmd를 실행하면 Ghost r2가 설치됩니다.

  2. 02

    Valheim과 프로필을 선택하세요.

    앱에서 Valheim → 사용할 플랫폼 → 프로필을 선택하세요. 데이터 경로를 옮겨 쓰고 있다면 Change data folder에서 기존 경로를 선택합니다.

  3. 03

    통합팩 설치를 누르세요.

    브라우저의 앱 열기 요청을 허용하면 선택한 프로필에 통합팩을 설치합니다. 설치를 마치면 앱의 Start modded로 게임을 실행하세요.

이후에는 앱에서 새 통합팩을 자동으로 확인합니다. 새 버전이 있으면 업데이트 버튼을 눌러 적용하세요. 전용 앱 자체의 새 설치 파일은 별도로 배포합니다.
