새 버전은 어떻게 받나요?+

Ghost r2 1.0.2 이상에서 Valheim 프로필을 열면 새 버전을 자동으로 확인합니다. 새 통합팩이 있으면 일반 모드와 같은 업데이트 목록과 Ghost 안내 바에 표시됩니다. ‘Ghost 업데이트’ 또는 기존 모드 업데이트 버튼으로 적용하세요. 실행 중에는 약 5분마다 다시 확인하며, 서버 PC가 켜져 있어야 새 팩을 받을 수 있습니다.

친구와 같은 모드 구성을 쓰고 싶어요.+

친구도 Ghost r2를 설치한 뒤 Import/Update → From code로 공유 코드를 가져오세요. 코드는 생성 당시의 프로필을 담으므로 Ghost 통합팩이 설치된 프로필에서 Export profile as code로 생성해야 합니다. 가져오기 미리보기에서 ‘Ghost 통합팩 포함’을 확인하세요.

기존 프로필과 설정은 어떻게 되나요?+

기본 데이터 경로의 기존 프로필을 사용할 수 있습니다. 원래 r2에서 데이터 폴더를 옮겼다면 Settings → Change data folder에서 같은 경로를 선택하세요. 일반 r2와 Ghost r2를 동시에 사용하지 마세요. 같은 DLL의 개별 모드가 남아 있다면 중복 설치를 먼저 정리하세요.
