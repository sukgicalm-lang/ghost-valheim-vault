# Ghost 해골 동행·길막힘 복귀 1.0.1

Ghost 통합팩 1.0.42에 포함됩니다. 별도 설치나 설정 변경 없이 적용됩니다.

- 체력바 오른쪽에 `방어막 413 / 450`처럼 남은 흡수량과 전체 흡수량을 표시합니다. 소유자는 실제 상태를 매 프레임 읽고, 다른 이용자는 동기화된 상태를 읽습니다. 피해·시전 시 즉시 동기화 요청, 평소 0.1초 간격 갱신입니다.
- 이동 후 이펙트가 사라지면 원래 게임의 `TriggerStartEffects`로 시각 효과만 복구합니다. 재시전에도 복구하며 방어막 시간·내구도를 새로 채우지 않습니다.
- 도착은 캐릭터 뒤쪽·양옆을 우선하고 몸 사이 최소 1m 여유를 둡니다. 안전한 자리가 없으면 위치 탐색을 재시도합니다. 캐릭터 위치에 겹쳐 놓는 대체 처리는 없습니다.
- 나를 따라오는 소환 해골은 지도 순간이동과 일반 포탈을 함께 이용합니다.
- 기존 해골을 이동하므로 체력·장비·등급·따라오기 명령을 유지합니다. 새 해골 생성이나 체력 회복은 하지 않습니다.
- 방어막의 남은 시간과 이미 소모한 흡수량을 보관합니다. 로딩 중에도 시간은 흐르며, 깨지거나 만료된 방어막을 되살리지 않습니다.
- 바위·단차를 점프로 넘어가 해골이 길을 못 찾으면 안전한 위치로 합류합니다. 약 4초 동안 가까워지지 못하고, 높이 차가 1.5m 이상이면서 거리 2.5m 이상이거나, 전체 거리가 12m 이상이면 복귀를 시도합니다.
- 합류는 플레이어가 땅에 서 있을 때만 시도합니다. 주변 바닥 높이와 해골이 설 공간을 확인합니다. 설 공간이 없으면 이동시키지 않습니다. 복귀 후 8초 동안 재복귀를 제한합니다.
- 평소에는 기본 게임의 걷기·전투·길찾기를 사용합니다. 플레이어의 점프 동작을 복제하는 기능은 아닙니다.
- 대기 명령의 해골, 적 해골과 다른 길들인 동물은 대상이 아닙니다. 최대 소환 수와 정상 사망·로그아웃 소환 해제는 유지합니다.
- 친구와 전용 서버도 같은 통합팩으로 업데이트해야 합니다.

자동 검사: 실제 제공된 게임 어셈블리의 패치·필드·바이너리 검사 31개, 관리 코드 동작 검사 65개 통과. 실제 게임 월드·그림·친구 PC·전용 서버의 실행 결과는 아직 확인하지 않았습니다. 빌드는 제공된 Valheim 1.0.20 참조를 사용했습니다. 실제 사용 중인 1.0.21에서의 실행 확인은 별도입니다.

## 개발 구조

성공한 `Player.TeleportTo`에서 시작해 `UpdateTeleport`가 끝난 실제 좌표로 이동합니다. 로딩 중 해당 해골 ZDO만 장면 제거에서 제외합니다. 해당 트랜잭션 동안 AI·물리 이동을 잠시 멈추고 체력·상태 효과 시간 처리는 계속합니다. 이동에 실패하면 게임이 돌려보낸 위치를 사용합니다. 통신이 끊기면 120초 후 해제합니다.

소유자가 해골 좌표와 방어막 상태를 저장한 다음 도착 플레이어에게 소유권을 넘기고 강제 ZDO 전송을 예약합니다. RPC의 플레이어 소유자·캐릭터 ID·이동 토큰을 확인합니다. 새 소유자·재생성된 인스턴스는 기록된 경과 시간을 차감하고 같은 방어막 피해량을 복원합니다.

추적 보완은 0.5초 간격으로 진행 상황을 확인하며 정상적으로 접근 중이면 개입하지 않습니다. 충돌 검사는 실제 `Physics.CheckCapsule`을 호출합니다. 게임·Unity 참조 DLL, 개인 설정과 세이브, 테스트용 doubles는 설치 ZIP에 포함하지 않습니다.

## 빌드

.NET Framework 4.8과 해당 netstandard facade, 실제 `assembly_valheim.dll`, `UnityEngine.dll`, `UnityEngine.CoreModule.dll`, `BepInEx.dll`, `0Harmony.dll`을 참조하는 결정적 Roslyn Release 빌드입니다. 프로젝트를 사용할 때 `VALHEIM_MANAGED`, `BEPINEX_PATH`를 지정합니다. 동작 테스트는 `dotnet run --project ../SummonTravel.Tests/Behavior.csproj --configuration Release`로 실행합니다.

## 1.0.41 이펙트 누락 수정 근거

이전 구현은 방어막의 수치만 복원했고 별도 네트워크 객체인 이펙트의 지역 제거·좌표·재생성은 처리하지 않았습니다. 게임의 기존 버프 재시전 경로는 시간을 갱신하지만 시작 이펙트는 다시 만들지 않습니다. 이번에는 이동 중 이펙트 ZDO도 유지하고 좌표를 갱신하며, 복원·재시전·유실 시 원래 이펙트를 다시 생성합니다. HUD의 남은 방어막은 실제 총 흡수량에서 누적 피해량을 뺀 값입니다. HUD 읽기로 상태 효과를 생성하지 않습니다.
