# Ghost 제련·제분 설정 1.0.2

일반 제련소·용광로·숯가마·풍차의 생산 속도와 최대 보관량을 조절합니다. 이번 버전은 Ghost에서 만든 모드들의 F1 이름·버튼·설명을 한글로 정리했습니다. 기존 설정과 게임 동작은 유지합니다.

게임을 종료하고 Ghost 런처를 다시 열면 자동으로 업데이트됩니다. 런처 재설치나 통합팩 재다운로드는 필요하지 않습니다.

## 생산 속도와 보관량

월드에 들어간 뒤 **F1 → Ghost 제련·제분 설정 → 원하는 시설**을 선택하세요.

| 항목 | 의미 |
| --- | --- |
| 원래 속도 | 게임에서 읽은 원래 처리 속도, 1배 |
| 2배·5배·10배 빠르게 | 같은 조건에서 처리 간격을 각각 절반·5분의 1·10분의 1로 설정 |
| 직접 입력 (배) | 1은 원래 속도, 10은 약 10배 빠르게. 입력 후 배수 적용 |
| 원료·석탄 최대 보관량 (개) | 시설 안에 넣어 둘 수 있는 최대 개수. 기본 100개 |
| 모드 기본 속도로 | 이 모드의 기본 속도로 복귀. 버튼에 해당 배수 표시 |

시설별 배수는 실제 게임에서 읽은 원래 시간을 기준으로 표시합니다. 월드 입장 전에는 기존 값을 유지하고, 기준 확인 후 배수 버튼을 표시합니다. 게임의 처리 주기와 묶음 배출 때문에 정확히 매초 한 개가 나오는 설정은 아닙니다. 풍차는 바람과 주변 가림의 영향을 계속 받습니다.

보관량은 생산량·생산물 하나당 재료 소모량·클릭 한 번의 투입량이 아닙니다. 0 이하는 원래 보관량을 사용합니다. 한도를 낮춰도 이미 넣은 원료는 삭제하지 않습니다.

## 다른 Ghost 모드의 한글 설정

- **Ghost 생활·성장 설정**: 발효 완료 시간은 분, 경험치는 배수, 벨트 무게는 착용 후 기준 총 한도로 표시합니다. 5분·경험치 2배·기준 무게 450처럼 숫자의 뜻을 설명합니다.
- **Ghost 외형 꾸미기**: 발헤임 체형·원작 체형과 사용·사용 안 함을 한글로 선택합니다. 크기·밝기·빛 흐름은 배수, 날개 농도는 퍼센트입니다. 현재 미사용인 이전 설정도 명확히 표시합니다.
- **지도 순간이동 (Ghost 수정)**: 지도에서 누를 키와 사용 방법을 한글로 설명합니다.
- 활 당김과 9발 강공격은 기존 고정 설정을 유지합니다. F1의 조절 항목 없는 모드 목록에도 고정 기능임을 한글로 표시합니다.

총 40개 설정의 제목·분류·설명과 선택 버튼을 정리했습니다. 항목 아래에도 설명을 표시하여 마우스를 올리지 않아도 읽을 수 있습니다. 서버나 모드에서 잠근 항목은 바꿀 수 없습니다.

한글 표시는 이 작은 제련·제분 모드가 담당합니다. 큰 외형 DLL이나 자산을 다시 받지 않아도 적용됩니다. 다른 Ghost 모드의 계산과 DLL은 유지합니다. 설정 파일 이름·키·저장값과 모드 식별자는 동일합니다. 설정을 열기만 해서는 저장값을 바꾸지 않습니다.

## 비상 수동 설치·교체

게임을 종료한 뒤 ZIP을 압축 해제하지 않고 r2modman의 **Import local mod**로 가져옵니다. Author Ghost / Name GhostSmelterControl / Version 1.0.2로 기존 같은 모드를 교체합니다. DLL을 다른 폴더에 추가 복사하지 마세요. 원본 FrizzQOL Smelter Control은 비활성화하거나 삭제하여 함께 로드되지 않게 하세요. cfg 파일은 배포본에 포함하지 않습니다.

함께 플레이하는 사람도 같은 모드 버전과 설정값을 사용하세요. 이번 패치는 설정값의 네트워크 동기화 기능을 추가하지 않습니다.

## 검증

실제 제공된 Valheim 1.0.20 게임 DLL로 컴파일하고 자동 검사 51개를 통과했습니다. F1 조작은 관리 코드의 시험용 화면 API로 검사했습니다. 실제 게임 화면·월드·서버에서의 실행 검증은 완료하지 않았습니다. 자세한 범위는 VALIDATION.md에 있습니다. 원본 FrizzQOL의 MIT 고지를 유지합니다.
