# Ghost 리니지 II 배경음악 1.0.2

GhostR2 통합팩 1.0.58이 음악 모드를 설치합니다. 발헤임을 실행하면 일반 설치 경로와 Windows에 등록된 설치 경로에서 리니지 II 클라이언트의 `music` 폴더를 찾습니다. 예를 들어 `D:\Lineage2_KR\music`에 있는 음원을 바로 읽습니다.

- 등록한 침대에서 수평 거리 100m 이내는 마을곡, 그 밖이나 침대를 등록하기 전에는 필드곡을 재생합니다.
- 발헤임이 전투 상태를 감지하면 전투곡을 우선 재생합니다. 전투가 끝나면 현재 위치에 맞는 음악으로 돌아갑니다.
- 각 목록을 무작위로 섞어 재생합니다. 발헤임의 음악 볼륨과 모드 볼륨 설정을 함께 적용합니다.
- 클라이언트를 별도 경로에 설치했다면 F1의 `LineageFolder`에 설치 폴더 또는 `music` 폴더를 지정할 수 있습니다.
- 프로필의 `BepInEx/config/GhostLineageMusic/Town`, `Field`, `Battle`에 직접 넣은 음원이 있으면 해당 목록에서 우선 사용합니다. 사용할 음원이 없는 상황에서는 발헤임 기본 음악이 재생됩니다.

모드에는 플레이어의 PC에서 음원을 읽는 기능이 포함됩니다. 리니지 II 클라이언트는 [공식 설치 안내](https://lineage2.plaync.com/)에서 받을 수 있습니다.
