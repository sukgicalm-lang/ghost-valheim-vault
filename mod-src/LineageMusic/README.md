# Ghost 리니지 II 배경음악 1.0.3

GhostR2 통합팩 1.0.59는 배경음악 모드와 음원 202곡을 함께 설치합니다. GhostR2에서 통합팩을 업데이트하고 **Start modded**로 발헤임을 실행하면 됩니다. 리니지 II 클라이언트나 별도 음원 경로 설정 없이 사용할 수 있습니다.

- 등록한 침대에서 수평 거리 100m 이내는 마을곡, 그 밖이나 침대를 등록하기 전에는 필드곡을 재생합니다.
- 발헤임이 전투 상태를 감지하면 전투곡을 우선 재생합니다. 전투가 끝나면 현재 위치에 맞는 음악으로 돌아갑니다.
- 각 목록을 무작위로 섞어 재생합니다. 발헤임의 음악 볼륨과 모드 볼륨 설정을 함께 적용합니다.
- 마을 78곡, 필드 66곡, 전투 58곡이 들어 있습니다. 말하는 섬, 기란, 글루디오, 아덴, 디온 테마가 포함됩니다.
- 프로필의 `BepInEx/config/GhostLineageMusic/Town`, `Field`, `Battle`에 직접 넣은 음원이 있으면 해당 목록에서 우선 사용합니다.
- 해당 목록에 직접 넣은 곡과 포함된 곡이 모두 없으면 리니지 II 클라이언트의 `music` 폴더를 찾습니다. F1의 `LineageFolder`에서 설치 폴더나 `music` 폴더를 직접 지정할 수도 있습니다. 사용할 곡이 없으면 발헤임 기본 음악이 재생됩니다.
